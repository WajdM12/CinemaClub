# نادي السينما - جامعة الملك سعود (التصميم الداكن)

الإصدار الداكن للموقع: خلفية سوداء، شعار النادي في الهيرو، وقسمين فقط: عن النادي وأهداف النادي.

## التشغيل محلياً
    python3 -m http.server 8000
ثم افتح http://localhost:8000

## الملفات
- `index.html`: الصفحة الرئيسية.
- `styles.css`: التصميم الداكن والاستجابة للشاشات.
- `script.js`: القائمة للجوال، حالة الترويسة عند التمرير، وإبراز الرابط النشط.
- `assets/logo.png`: شعار النادي كما هو بدون تعديل.

## النشر
يعمل كموقع ثابت على GitHub Pages أو Netlify أو Cloudflare Pages.
